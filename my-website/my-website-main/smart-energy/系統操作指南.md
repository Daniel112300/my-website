## 📋 功能 1：電器開關控制

### 用途
- 查看所有設備的開關狀態
- 遠端控制設備開關
- 查看所有設備詳細資訊
- 新增設備
- 刪除設備

### API 端點（5 個）

#### 1.1 查看所有設備狀態
```http
GET /device/state
```

**回應範例：**
```json
{
  "ok": true,
  "state": {
    "客廳LED燈": false,
    "客廳冷氣": true,
    "書房檯燈": false
  }
}
```

#### 1.2 切換設備開關
```http
PATCH /device/toggle
Content-Type: application/json

{
  "name": "客廳冷氣",
  "on": true
}
```

### 使用範例

```powershell
# 查看狀態
Invoke-RestMethod -Uri "http://127.0.0.1:5000/device/state"

# 開啟客廳冷氣
$body = @{ name = "客廳冷氣"; on = $true } | ConvertTo-Json
Invoke-RestMethod -Uri "http://127.0.0.1:5000/device/toggle" `
  -Method PATCH -Body $body -ContentType "application/json"

# 關閉客廳冷氣
$body = @{ name = "客廳冷氣"; on = $false } | ConvertTo-Json
Invoke-RestMethod -Uri "http://127.0.0.1:5000/device/toggle" `
  -Method PATCH -Body $body -ContentType "application/json"
```

```http
GET /device/list
```


## 📊 功能 2：每日用電統計

### 用途
- 查詢每日/每月/每年用電量
- 計算台電累進費率電費
- 比較不同時間段用電
- 新增用電記錄

### API 端點（8 個）

| 端點 | 方法 | 功能 |
|------|------|------|
| `/usage/daily` | GET | 每日統計（預設近 7 天） |
| `/usage/monthly/<year>/<month>` | GET | 月統計 |
| `/usage/yearly/<year>` | GET | 年統計 |
| `/usage/bill` | POST | 電費試算 |
| `/usage/compare` | GET | 時間段比較 |
| `/usage/add` | POST | 新增單筆記錄 |
| `/usage/batch` | POST | 批次新增 |

### 使用範例

#### 查詢每日用電（預設近 7 天）
```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:5000/usage/daily"
```

**⚠️ 重要：預設顯示今天往前推 7 天**
- 今天是 11/30 → 顯示 11/24 ~ 11/30
- 即使資料庫有 12 月數據，預設也不會顯示

#### 查詢指定日期範圍
```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:5000/usage/daily?start_date=2025-12-01&end_date=2025-12-07"
```

#### 查詢單月統計
```powershell
# 查詢 2025 年 11 月
Invoke-RestMethod -Uri "http://127.0.0.1:5000/usage/monthly/2025/11"
```

#### 電費試算
```powershell
$body = @{ kwh = 330; month = 7 } | ConvertTo-Json
Invoke-RestMethod -Uri "http://127.0.0.1:5000/usage/bill" `
  -Method POST -Body $body -ContentType "application/json"
```

#### 時間段比較
```powershell
# 比較 10 月和 11 月
Invoke-RestMethod -Uri "http://127.0.0.1:5000/usage/compare?period_type=month&date1=2025-10&date2=2025-11"
```

## 🌡️ 功能 3：溫度自動控制

### 用途
- 自動讀取溫度並控制冷氣
- 背景監控（每 3 分鐘自動檢查）
- 系統設定（目標溫度、監控間隔）

### API 端點（8 個）

| 端點 | 方法 | 功能 |
|------|------|------|
| `/auto/check` | GET | 🔥 **立即檢查並控制**（推薦） |
| `/auto/monitor/start` | POST | 啟動背景監控 |
| `/auto/monitor/stop` | POST | 停止背景監控 |
| `/auto/monitor/status` | GET | 查詢監控狀態 |
| `/auto/config` | GET | 查看系統設定 |
| `/auto/config` | POST | 修改系統設定 |
| `/auto/decide` | GET/POST | 手動測試（給前端用） |

### 核心功能：自動溫度檢查

```powershell
# 立即檢查溫度並控制所有冷氣
Invoke-RestMethod -Uri "http://127.0.0.1:5000/auto/check"
```

**系統會自動：**
1. 從資料庫讀取最新溫度（`EnvironmentLog` 表）
2. 如果沒有資料，呼叫模擬器計算溫度
3. 與目標溫度（預設 26°C）比較
4. 自動開啟或關閉**所有冷氣設備**
5. 更新資料庫中的設備狀態

**回應範例：**
```json
{
  "ok": true,
  "current_temp": 23.3,
  "target_temp": 26.0,
  "action": "turn_off",
  "reason": "目前溫度 23.3°C 低於目標 26.0°C，關閉冷氣",
  "timestamp": "2025-11-30 17:47:34",
  "devices_controlled": [
    {"device_id": 2, "device_name": "客廳冷氣", "action": "turn_off", "success": true},
    {"device_id": 5, "device_name": "臥室冷氣", "action": "turn_off", "success": true}
  ]
}
```

### 背景監控（每 3 分鐘自動執行）

```powershell
# 啟動監控（每 180 秒檢查一次）
$body = @{ interval = 180 } | ConvertTo-Json
Invoke-RestMethod -Uri "http://127.0.0.1:5000/auto/monitor/start" `
  -Method POST -Body $body -ContentType "application/json"

# 查詢監控狀態
Invoke-RestMethod -Uri "http://127.0.0.1:5000/auto/monitor/status"

# 停止監控
Invoke-RestMethod -Uri "http://127.0.0.1:5000/auto/monitor/stop" -Method POST
```

### 修改系統設定

```powershell
# 查看當前設定
Invoke-RestMethod -Uri "http://127.0.0.1:5000/auto/config"

# 修改目標溫度為 25°C，監控間隔為 2 分鐘
$body = @{ target_temp = 25.0; monitor_interval = 120 } | ConvertTo-Json
Invoke-RestMethod -Uri "http://127.0.0.1:5000/auto/config" `
  -Method POST -Body $body -ContentType "application/json"
```

## 🎲 功能 4：資料模擬器

### 用途
- 產生測試用的用電數據
- 模擬溫度變化
- 不需要真實硬體即可開發

### ⚠️ 重要觀念

**模擬器不會自動執行！**
- ❌ 啟動伺服器不會產生數據
- ❌ 重啟伺服器不會增加記錄
- ❌ 沒有定時自動產生功能
- ✅ **必須手動呼叫 API** 才會產生數據

### API 端點（5 個）

| 端點 | 方法 | 功能 |
|------|------|------|
| `/simulate/daily` | POST | 模擬單日用電 |
| `/simulate/range` | POST | 批次模擬多天 |
| `/simulate/temperature` | GET | 計算指定時刻溫度 |
| `/simulate/config` | GET | 查看模擬器設定 |
| `/simulate/stats` | GET | 資料庫統計 |

### 使用範例

#### 預覽單日數據（不存資料庫）
```powershell
$body = @{
    date = "2025-12-15"
    save_to_db = $false
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://127.0.0.1:5000/simulate/daily" `
  -Method POST -Body $body -ContentType "application/json"
```

#### 產生一週數據並存入資料庫
```powershell
$body = @{
    start_date = "2025-12-01"
    end_date = "2025-12-07"
    save_to_db = $true
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://127.0.0.1:5000/simulate/range" `
  -Method POST -Body $body -ContentType "application/json"
```

#### 查詢指定時刻溫度
```powershell
# 查詢 7 月 15 日下午 2 點的溫度
Invoke-RestMethod -Uri "http://127.0.0.1:5000/simulate/temperature?date=2025-07-15&hour=14"
```

#### 查看資料庫統計
```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:5000/simulate/stats"
```

### 模擬器產生的數據

#### 會寫入資料庫：
- ✅ **用電記錄**（`power_logs` 表）
  - device_id, power_watts, hours, kwh, log_date

#### 不會自動寫入：
- ❌ **溫度記錄**（只計算，不存入 `environment_logs`）

### 模擬數據 vs 真實數據

| 項目 | 說明 |
|------|------|
| **寫入位置** | 同一個 `power_logs` 表 |
| **能否區分** | ❌ 無法自動區分 |
| **會顯示在 `/usage/daily` 嗎** | ✅ 會！完全一樣 |
| **建議做法** | 真實數據與模擬數據用不同日期範圍 |

## 🔍 重要觀念釐清

### ❓ `/usage/daily` 為什麼沒顯示 12 月數據？

**原因：預設只顯示近 7 天**

```python
# 程式邏輯
end_date = date.today()              # 今天（11/30）
start_date = end_date - timedelta(days=6)  # 往前 6 天（11/24）

# 查詢範圍：2025-11-24 ~ 2025-11-30
# 12 月的數據不在此範圍內！
```

**解決方法：**
```powershell
# 手動指定日期範圍
Invoke-RestMethod -Uri "http://127.0.0.1:5000/usage/daily?start_date=2025-12-01&end_date=2025-12-07"
```

---

### ❓ 模擬器產生的數據在哪裡？

**流程：**
```
POST /simulate/daily
    ↓
寫入 power_logs 表
    ↓
GET /usage/daily 讀取
    ↓
顯示數據（無差異）
```

**驗證：**
```powershell
# 1. 產生數據
$body = @{ date = "2025-12-10"; save_to_db = $true } | ConvertTo-Json
Invoke-RestMethod -Uri "http://127.0.0.1:5000/simulate/daily" `
  -Method POST -Body $body -ContentType "application/json"

# 2. 查詢數據（必須指定日期）
Invoke-RestMethod -Uri "http://127.0.0.1:5000/usage/daily?start_date=2025-12-10&end_date=2025-12-10"
```

---

### ❓ 如何清空測試數據？

```sql
-- 直接在 MySQL 中執行
DELETE FROM power_logs WHERE log_date >= '2025-12-01';
```

或者只刪除特定日期：
```sql
DELETE FROM power_logs WHERE log_date = '2025-12-10';
```

## 🚨 疑難排解

### 問題 1：無法連接至遠端伺服器
**原因**：Flask 伺服器未啟動  
**解法**：執行 `python app.py`

### 問題 2：ModuleNotFoundError
**原因**：缺少 Python 套件  
**解法**：
```powershell
pip install flask flask-sqlalchemy pymysql python-dotenv
```

### 問題 3：資料庫連接失敗
**原因**：MySQL 未啟動或密碼錯誤  
**解法**：
1. 檢查 MySQL 服務是否運作
2. 確認 `config.py` 中的資料庫密碼

### 問題 4：模擬器沒產生數據
**原因**：`save_to_db` 設為 `false`  
**解法**：確認 JSON body 中 `"save_to_db": true`

### 問題 5：`/usage/daily` 沒有數據
**原因 A**：資料庫真的沒有資料  
**解法 A**：用模擬器產生數據

**原因 B**：數據不在預設 7 天範圍內  
**解法 B**：手動指定日期參數
```powershell
?start_date=2025-12-01&end_date=2025-12-07
```

## 💡 給前端開發者的建議

### 1. 先用 PowerShell 測試 API
在寫前端代碼之前，先用 PowerShell 確認 API 回應格式：
```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:5000/usage/daily"
```

### 2. 產生固定測試數據
使用相同的 `seed` 確保所有組員數據一致：
```powershell
$body = @{ start_date = "2025-01-01"; end_date = "2025-12-31"; save_to_db = $true; seed = 2025 } | ConvertTo-Json
Invoke-RestMethod -Uri "http://127.0.0.1:5000/simulate/range" -Method POST -Body $body -ContentType "application/json"
```

### 3. JavaScript Fetch 範例
```javascript
// 查詢每日用電
fetch('http://127.0.0.1:5000/usage/daily')
  .then(response => response.json())
  .then(data => {
    console.log(data);
    // 渲染到頁面
  });

// 切換設備開關
fetch('http://127.0.0.1:5000/device/toggle', {
```
