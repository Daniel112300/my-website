#### 2.5 時間段比較
```
GET /usage/compare?period_type=month&date1=2025-10&date2=2025-11
GET /usage/compare?period_type=day&date1=2025-11-01&date2=2025-11-30
GET /usage/compare?period_type=year&date1=2024&date2=2025
```

**參數說明**：
- `period_type`: 比較類型 (`day`, `month`, `year`)
- `date1`: 第一個時間點
  - 日：`2025-11-01`
  - 月：`2025-10`
  - 年：`2025`
- `date2`: 第二個時間點（格式同 `date1`）

**回應範例**：
```json
{
  "ok": true,
  "period_type": "month",
  "period1": {
    "label": "2025-10",
    "kwh": 420.5,
    "cost": 1261.5,
    "record_count": 93
  },
  "period2": {
    "label": "2025-11",
    "kwh": 380.2,
    "cost": 1140.6,
    "record_count": 79
  },
  "comparison": {
    "kwh_difference": -40.3,
    "cost_difference": -120.9,
    "kwh_percent_change": -9.58,
    "cost_percent_change": -9.59
  }
}
```

**前端需求**：
- [ ] 建立「時間段比較」頁面
- [ ] 提供比較類型選擇器（日/月/年）
- [ ] 提供兩個日期選擇器（根據比較類型顯示不同精度）

#### 3.2 🆕 **自動溫度檢查（推薦使用）**
```
GET /auto/check
```

- 自動從資料庫讀取最新溫度記錄（`EnvironmentLog` 表）
- 若資料庫無資料，會呼叫模擬器計算當前溫度
- 根據溫度自動控制所有冷氣設備
- 更新資料庫中的設備開關狀態

**回應範例**：
```json
{
  "ok": true,
  "current_temp": 23.3,
  "target_temp": 26.0,
  "action": "turn_off",
  "reason": "目前溫度 23.3°C 低於目標 26.0°C，關閉冷氣",
  "timestamp": "2025-11-30 17:47:34",
  "devices_controlled": [
    {
      "device_id": 2,
      "device_name": "客廳冷氣",
      "action": "turn_off",
      "success": true
    },
    {
      "device_id": 5,
      "device_name": "臥室冷氣",
      "action": "turn_off",
      "success": true
    },
    {
      "device_id": 6,
      "device_name": "臥室冷氣",
      "action": "turn_off",
      "success": true
    },
    {
      "device_id": 7,
      "device_name": "測試冷氣",
      "action": "turn_off",
      "success": true
    }
  ]
}
```

**前端需求**：
- [ ] 建立「即時溫度監控」頁面

#### 3.3 🆕 **啟動背景監控**
```
POST /auto/monitor/start
Content-Type: application/json

{
  "interval": 180
}
```

**功能說明**：
- 啟動背景執行緒，每隔指定秒數自動檢查溫度
- 預設間隔：180 秒（3 分鐘）

**回應範例**：

  "ok": true,

## 🎨 建議的前端技術選擇

### 選項 A：純 HTML + JavaScript（簡單）
- 使用 `fetch()` 或 `axios` 呼叫 API
- 用 Chart.js 或 ECharts 繪製圖表
- 適合快速原型開發

### 選項 B：前端框架（推薦）
- **React** + Ant Design / Material-UI
- **Vue.js** + Element Plus
- **Next.js**（如果需要 SSR）

### 選項 C：Flask 模板渲染（最簡單）
- 在 Flask 中直接使用 Jinja2 模板
- 後端先處理資料，直接傳給 HTML 顯示
- 不需要額外的前端框架

// 解析 CSV 檔案
function parseCSV(file) {
  return new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.onload = (e) => {
      const lines = e.target.result.split('\n');
      const records = lines.slice(1).map(line => {
        const [device_id, kwh, date] = line.split(',');
        return {
          device_id: parseInt(device_id),
          kwh: parseFloat(kwh),
          date: date.trim()
        };
      });
      resolve(records);
    };
    reader.readAsText(file);
  });
}

    body: JSON.stringify({records})
  })
